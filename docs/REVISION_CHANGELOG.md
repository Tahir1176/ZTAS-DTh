# REVISION_CHANGELOG.md — v1 → v2 (major revision)

## Corrections of errors in v1
1. **Provenance effect inflated (C1).** v1 applied provenance checks to every cross-phase lateral move. v2 introduces
   artifact- vs interface-mediated flows (f_art, default 0.5, swept). Consequence: provenance is no longer the dominant
   mechanism; ZT+prov compromises 0.49 (not ≈0.14) of the reference thread.
2. **Merkle duplication collision (C13).** Odd-node duplication without leaf-count binding; fixed (promotion + signed
   header with n, root, gateway, first sequence number). Found by direct script and by model checker M3.
3. **Unsafe evidence rule (C12).** κ = 2 without decay isolates up to 8% of legitimate devices per shift (heavy-tailed
   scores). New default: decay (h = 30) + outage-aware, κ = 3; v1 rule retained only as a variant.
4. **Block tier mismatch (C4).** Code isolated; paper said deny + alert. Now deny + alert + 2 evidence units.
5. **Unfair baseline (C3).** ZTAS-DTh lacked static ZT's generic monitoring; now a strict superset.
6. **Unpaired comparisons and naive CIs (C5, C6).** Common random numbers; hierarchical bootstrap; per-graph results; d_z.
7. **Overstated throughput (C16).** "1.1×10⁵ records/s" removed; replaced by a latency/utilisation model.
8. **ECDSA key size (C15).** 64 → 65 B.
9. **Unsupported thesis claims** (formal model checking, 60% attack-surface reduction) remain excluded and are now
   explicitly disclaimed in Limitations.
